WHAT YOU'RE SEEING
  • Portfolio Equity is the current total value of the simulated V4 portfolio. The gain/loss compares it with the original $100,000 paper capital.
  • The chart includes a synthetic $100,000 starting baseline, every recorded V4 journal observation, and a read-only Current point using the latest mark-to-market equity.
  • Total Return Since Start compares current equity with the original $100,000. Journal Forward Return measures only the change between recorded journal observations.
  • If several observations share a calendar date, the chart shows time-of-day labels so they are distinguishable.
  • 60% of the portfolio targets SPY and 40% targets the current V4 Top Five. No real brokerage orders are placed.
