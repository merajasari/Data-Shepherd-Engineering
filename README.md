# Data Shepherd Engineering

A portfolio repository showcasing enterprise data engineering solutions using modern Azure and Microsoft data platforms.

## About This Repository

This project demonstrates data engineering patterns, architecture, and implementation examples including:

- Microsoft Fabric and OneLake
- Azure Data Factory
- Azure Data Lake Storage Gen2
- Azure Databricks
- Delta Lake
- Azure Synapse Analytics
- SQL Server
- Power BI
- Python data engineering workflows

## Architecture Focus

The repository follows modern lakehouse and Medallion Architecture principles:

- Bronze Layer: Raw data ingestion
- Silver Layer: Cleansed and transformed data
- Gold Layer: Business-ready analytical models
